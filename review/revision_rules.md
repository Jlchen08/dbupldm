# TLQLDMR Revision Rules

Use this document before any further edits to the paper or response letter.

1. `Original` text in the response letter must be copied from `/home/user/dbupldm/DBUPLDM_BDR3` and `/home/user/dbupldm/DBUPLDM_BDR3_Supplementary`.
2. The paper text in `/home/user/dbupldm/DBUPLDM_BDR4` must read like a normal manuscript, not like a rebuttal.
3. The `Author response` must answer the reviewer's concern by explaining what the revised manuscript now says, shows, or concludes. It should read like a direct answer to the comment, not like a generic statement that something was revised.
4. The `Author response` should be understandable without reading `Author action`. It must summarize the substantive revision or result in concrete terms.
5. The `Author action` should give the exact paper replacement, including original text and revised text. For purely added content with no counterpart in the original manuscript, use `Added text` instead of `Original text`.
6. Any revised text shown in `/home/user/dbupldm/DBUPLDM_response_4st/main.tex` must match the actual revised manuscript text.
7. When a paper paragraph is changed, update the corresponding response entry in the same turn so the `Original text` / `Revised text` pair stays consistent.
8. Use the original manuscript as the source of truth whenever there is any doubt about what the `Original text` should be.
9. Experimental results must satisfy academic integrity requirements: do not fabricate, manually alter, cherry-pick, or post-hoc filter results in a way that creates misleading conclusions. Experiments must be reproducible, methodologically convincing, and directly responsive to the reviewer concern so that the evidence can withstand scrutiny.
10. In the revised manuscript, mark only newly added or substantively modified sentences in red. Do not wrap an entire paragraph in blue when only part of it changed, so reviewers can locate revisions quickly.
11. In the response letter, show the quoted `Revised text` in red while keeping the quoted `Original text` in black, so the modification is immediately visible.
12. Every non-empty `Author action` in the response letter must start with a standalone location line on its own row, formatted as a centered red-framed box, e.g. `▸▸ Location in the revised manuscript: Section~5.3, Table~7 ...`, so reviewers can find each modification without searching. Add the page number (e.g. `page 25`) once it is known from a compiled manuscript.

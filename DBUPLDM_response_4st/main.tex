\subsubsection*{\underline{\textbf{Reviewer 8, Strength 4}}}
\emph{The scalability discussion (ADMM, mini-batch, Random Fourier Features) at least acknowledges the journal's scope, even if it is not yet demonstrated.}
}


{\color{customgreen}
\subsubsection*{\underline{\textbf{Reviewer 8, Major Concern 1}}}
\emph{The LDAM configuration as described is methodologically incoherent. The authors write that LDAM ``adapts ResNet-18 for tabular data.'' ResNet-18 is a 2D convolutional architecture designed for image inputs. There is no standard way to apply it to tabular features of dimension 3 to 61, which is the range in Table 1. The authors need to explain exactly what architecture was used, replace it with a sensible tabular backbone (MLP with LDAM loss would be the natural choice), or drop the claim. As it stands, readers cannot reproduce or evaluate this baseline.}
}


{\color{black}
\subsubsection*{\textbf{\underline{Author response}}}
We thank the reviewer for identifying the architectural inconsistency. We implemented LDAM with a tabular MLP backbone rather than ResNet-18: two hidden layers of 128 and 64 units with batch normalization, ReLU, and dropout 0.3. The LDAM loss uses class-dependent margins with maximum margin $\Delta=0.5$, scale 30, and deferred class reweighting after epoch 160. DeepSMOTE and Balanced Softmax are also implemented with explicit tabular architectures, and all three baselines are evaluated by stratified 5-fold cross-validation. Thus, the revised comparison is directly applicable to feature vectors with 3--61 dimensions and is reproducible from the released implementation.
}

\textbf{Revised text:} ``{\color{red}We additionally evaluate three recent imbalance-learning baselines using tabular architectures. DeepSMOTE uses an encoder--decoder with latent dimension 128 and encoder widths 256--128--64; minority samples are interpolated among latent-space nearest neighbors and decoded before classification, with reconstruction penalty weight 0.1. LDAM uses the same two-hidden-layer tabular MLP backbone as the other neural baselines, class-dependent margins with maximum margin $\Delta=0.5$, scale 30, and deferred class reweighting after epoch 160. {\color{black}
\subsubsection*{\textbf{\underline{Author response}}}
We thank the reviewer for asking for the test setup: the identical p-values are expected, not an error. Each of the four Wilcoxon signed-rank tests pairs the per-$\eta$ win counts of DBUPLDM against one baseline (SVM, UPSVM, PinSVM, or LDM) across the six $\eta$ settings, so there are $n=6$ paired observations per comparison (the WIN rows of the win/draw/loss table). DBUPLDM records more wins than each baseline at every $\eta$ value, i.e., all six paired differences favor DBUPLDM in every comparison, for which the exact two-sided p-value is $2/2^6=0.03125$ in all four cases. The revised manuscript now states this setup explicitly and additionally reports effect sizes: the matched-pairs rank-biserial correlation is $1.00$ and the standardized effect size is $r=Z/\sqrt{n}\approx 0.90$ ($Z\approx 2.20$), both indicating a large effect.
